ORVYN 2.2.0 - установка

1. Запусти OrvynSetup-2.2.0.exe.
2. Прочитай пользовательское соглашение и политику использования.
3. Поставь галочку «Я принимаю пользовательское соглашение и политику использования» и нажми «Установить».
4. Установщик закроет старый ORBIT, положит браузер в %LOCALAPPDATA%\Programs\ORVYN, создаст ярлыки и запустит ORVYN.

В папке установки должны быть два файла: ORVYN.exe и WebView2Loader.dll.
Удалять WebView2Loader.dll нельзя — без него Windows не запустит браузер.
Если запускаешь без установки, распакуй ZIP целиком и запускай ORVYN.exe из папки, где лежат оба файла.

Нужен Microsoft Edge WebView2 Runtime. На Windows 10 и 11 он обычно уже стоит.
Если нет — поставить бесплатно: https://go.microsoft.com/fwlink/p/?LinkId=2124703

Если Windows показывает SmartScreen: «Подробнее» → «Выполнить в любом случае».
Это нормально для сборки без платной подписи кода.
